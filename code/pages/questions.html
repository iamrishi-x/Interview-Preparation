Question 17 of 50 · MCP security and governance. Think first, then reveal and self-evaluate.

Difficulty: Senior

How would you secure MCP tool invocation in an enterprise system?

Cover authentication, authorization, least privilege, policy checks, auditing, and fallback behavior.

Ideal answer outline

  • Authenticate caller and tool server identity.
  • Authorize per-tool and per-resource action with scoped policies.
  • Apply least privilege with explicit deny defaults.
  • Validate input/output and log all tool calls with trace IDs.
  • Handle failures with bounded retries and safe fallback responses.
