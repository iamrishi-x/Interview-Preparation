Topic Deep Dive

Agentic AI and Multi-Agent Systems

Focus areas from the roadmap: agent loops, tool orchestration, multi-agent tradeoffs, LangGraph, and memory.

Core Agent Concepts

  1. Goal -> Plan -> Tool selection -> Execute
  2. Observe -> Reason -> Next action
  3. Validation + retries -> final answer

What to Study

  • Agent architecture and feedback loop agent-architecture
  • Planning and tool selection logic agent-planning
  • State management and validation paths agent-state
  • Error handling and retry strategy agent-retries

Interview Questions

  • What separates a tool-calling chain from a true agent loop?
  • How do you prevent infinite or unproductive loops?
  • Where do you enforce human-in-the-loop approvals?

Single Agent vs Multi-Agent

What to Study

  • Supervisor, router, planner/executor patterns agent-pattern-supervisor
  • Sequential vs parallel coordination models agent-pattern-parallel
  • Agent coordination and shared state boundaries agent-coordination
  • Overhead and failure risks in multi-agent systems agent-risk

Interview Questions

  • When is a single agent enough?
  • What disadvantages appear when teams overuse multi-agent architectures?
  • How do you debug agent coordination failures in production?

LangGraph for Controlled Agent Workflows

  1. Model workflow as state + nodes + conditional edges
  2. Add checkpoints, interrupts, and persistence
  3. Support retries and human approvals on risk nodes

What to Study

  • State schema and edge transitions langgraph-state
  • Conditional routing and node specialization langgraph-conditional
  • Persistence, checkpoints, and interrupts langgraph-persistence
  • Retry/failure handling and recursion control langgraph-retry

Interview Questions

  • Why choose LangGraph over a linear chain?
  • How do conditional edges map to business logic decisions?
  • How do you prevent recursive failure loops?

Agent Memory and Guardrails

What to Study

  • Short-term vs long-term memory boundaries memory-short-long
  • Semantic, episodic, summary, and vector memory memory-types
  • Memory growth control and pruning strategy memory-growth
  • Cases where memory should be disabled memory-not-needed

Interview Questions

  • How do you persist state without polluting future tasks?
  • When does memory hurt quality or safety?
  • How do you tie memory decisions to cost and latency constraints?
