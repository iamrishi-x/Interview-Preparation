Roadmap and Study Sequence

Goal: prepare for senior GenAI / AI Engineer roles through strong fundamentals, system architecture clarity, and project-backed interview stories.

Phase 1: LLM Foundation

Transformers, attention, tokens/context windows, embeddings, decoding.

Phase 2-3: RAG and Agents

RAG architecture, advanced retrieval, evaluation, tool calling, multi-agent design, LangGraph, memory.

Phase 4-6: MCP and System Design

MCP architecture/security, AI coding agents, Neo4j knowledge graphs, enterprise architecture patterns.

Phase 7-10: Engineering to Interview

Python/FastAPI/PostgreSQL/Azure, security, observability, project deep dives, behavioral stories.

Story 1: Diesel Direct

AI-powered software modernization

  1. .NET 4.8 source inventory with Roslyn parser and AST extraction

  3. Multi-agent architecture with MCP-based tool integration
  4. .NET 10 + React generation with validation and build/test gates

Story 2: FCC

Production contract intelligence RAG

  1. Contract ingestion via document intelligence and field extraction
  2. Embeddings + hybrid retrieval + query rewriting + reranking
  3. LLM answer stage with memory and evaluation loops
  4. Cost and quality tracking for production reliability

Story 3: Plexis

  1. Agent routes user query across RAG and SQL paths
  2. Hybrid retrieval + validated text-to-SQL generation
  3. Multi-hop reasoning over PostgreSQL with safeguards
  4. Auditable answer with traceable retrieval and query path
